# Survey-of-Programming-Languages

### For Module 3

* cd into studentapi
* run ./mvnw spring-boot:run
* visit localhost:8080/api/courses to view courses
* visit localhost:8080/api/student to greet student
* use student?name="insert name here" to get a personalized greeting
  * for example: localhost:8080/api/student?name=Delaney will return "Welcome, Delaney!"
